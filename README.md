## Что это

Плагин добавляет предмет «сигарета» с собственной моделью и полноценным жизненным циклом привычки. Выкурил одну — получил бафф. Выкурил сотню — не можешь без них жить: замедление, слабость, тошнота и урон по таймеру, пока не закуришь снова.

Всё поведение настраивается через `config.yml`, включая эффекты каждого уровня зависимости, длительность затяжки и рецепт крафта.

## Как это работает

### Затяжка

Курение построено на ванильном компоненте `CONSUMABLE`, поэтому анимацию и шкалу использования рисует сам клиент, без подделки пакетов.

1. Зажимаешь ПКМ с сигаретой в руке.
2. Пока держишь — изо рта идёт дым, в actionbar тикает полоса прогресса.
3. Сдвинулся с места, отпустил кнопку или убрал сигарету — затяжка прервана, предмет остался цел.
4. Доводишь до конца — сигарета сгорает, приходят баффы, дебаффы ломки снимаются.

Кулдаун списывается только при успешном завершении, так что прерванная попытка ничего не стоит.

### Зависимость

Уровень считается от количества выкуренного:

| Уровень | Сигарет | Ломка через | Эффекты |
|---|---|---|---|
| Лёгкая | 11+ | 32 мин | замедление |
| Средняя | 31+ | 27 мин | замедление II, слабость |
| Сильная | 61+ | 22 мин | замедление II, слабость II, усталость |
| Критическая | 101+ | 18 мин | всё выше + тошнота, голод, урон каждые 37 с |

Если включить `decay-minutes-per-cigarette`, зависимость постепенно спадает без курения — тогда бросить реально возможно. По умолчанию выключено.

### Крафт

Два столбца бумаги, порох по центру — на выходе 6 сигарет.

Ингредиенты и выход настраиваются в `config.yml`. Сигареты не подходят под ванильные рецепты бумаги, так что книгу или ракету из них не собрать.

## Команды

| Команда | Право | Что делает |
|---|---|---|
| `/cigarette` | — | справка по доступным подкомандам |
| `/cigarette stats` | `cigarette.use` | своя статистика курения |
| `/cigarette give <игрок> [кол-во]` | `cigarette.give` | выдать сигареты |
| `/cigarette addiction <игрок>` | `cigarette.admin` | зависимость игрока |
| `/cigarette reset <игрок>` | `cigarette.admin` | сбросить зависимость |
| `/cigarette reload` | `cigarette.admin` | перечитать конфиг и рецепт |

Алиас — `/cig`.

## Права

| Право | По умолчанию |
|---|---|

| `cigarette.use` | все |
| `cigarette.give` | оператор |
| `cigarette.admin` | оператор |

## Установка

1. Собери или скачай `Cigarette-1.0.0.jar`, положи в `plugins/`.
2. Раздай игрокам ресурспак `Cigarette-resourcepack-1.0.0.zip` из `build/resourcepack/` — без него сигарета выглядит как бумага.
3. Запусти сервер, настрой `plugins/Cigarette/config.yml`, применяй изменения через `/cigarette reload`.

## Сборка

```bash
./gradlew clean build
```

Готовый jar появится в `build/libs/`, ресурспак — в `build/resourcepack/`.

## Настройка

Основное в `config.yml`:

```yaml
cooldown-seconds: 5

smoking:
  duration-seconds: 3.0      # сколько держать ПКМ
  animation: TOOT_HORN       # поза при затяжке
  interrupt-on-move: true    # обрывать при движении
  show-progress: true        # полоса в actionbar

recipe:
  enabled: true
  paper: PAPER
  filler: GUNPOWDER
  result-amount: 6

addiction:
  decay-minutes-per-cigarette: 0   # 0 = зависимость не спадает
```

Эффекты ломки задаются списком для каждого уровня и обновляются короткими интервалами, поэтому спадают сразу после сигареты, а не висят минутами.
